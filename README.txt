診療収益 Web/PWA版

ファイル一式をWebサーバー（例: GitHub Pages）へ置いてください。
iPhoneではSafariで公開URLを開き、共有 → ホーム画面に追加、でアプリのように使えます。

・入力はブラウザのlocalStorageに保存
・本日の収益は画面上部に固定
・よく使う処置は＋/−
・その他の処置は未選択がデフォルト、追加後に未選択へ戻る
・「1つ戻す」「リセット」対応
・Service Workerにより、一度読み込んだ後はオフライン利用可能


v2追加機能
・右上「集計」
・月カレンダー
・月収益、診療日数、1日平均
・月の日別一覧
・日付タップでその日の処置内訳
・旧v1の当日データを初回のみ引き継ぎ


v2.1
・ボタンや選択欄で touch-action: manipulation を使用し、連打時のダブルタップズームを抑制
・ピンチズーム自体は無効化していません
